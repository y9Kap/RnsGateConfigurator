# Changelog

Формат основан на «Keep a Changelog» и придерживается Semantic Versioning.

## [1.2.2] - 2026-03-30
### Added
- Возможность просмотра детального состояния Wi-Fi сети (аналог `wpa_cli status`) непосредственно из конфигуратора.
- Кнопка «Обновить статус» для получения актуальных данных о подключении с сервера.

## [1.2.1] - 2026-01-17
### Added
- Проверка на дублирование интерфейсов: теперь в конфигураторе может быть не более одного интерфейса типа SPI Lora (`loraspi`) и не более одного типа FreeDV (`freedv`). При попытке выбрать дублирующий тип выводится уведомление (toast).

## [1.2.0] - 2026-01-16
### Added
- [TEST FEATURE] Система авторизации и управления пользователями:
  - Первый зарегистрированный пользователь автоматически получает права администратора.
  - Администратор может добавлять и удалять других пользователей через новый раздел «Пользователи».
  - Самостоятельная регистрация новых пользователей закрыта, если в системе уже есть хотя бы один пользователь.
- [TEST FEATURE] Расширенные возможности для администратора:
  - Снято ограничение на количество создаваемых конфигураций интерфейсов (для обычных пользователей сохраняется лимит в 1 конфиг).

## [1.1.0] - 2026-01-16
### Added
- Интернационализация (i18n): добавлена поддержка двух языков (русский и английский). Весь интерфейс теперь локализован.
- Переключатель языка: в нижнюю часть сайдбара добавлен выпадающий список для выбора языка интерфейса. Выбранный язык сохраняется в браузере.
- Видимость пароля: для всех полей ввода пароля (WiFi, AP) добавлены иконки «глаза», позволяющие переключать видимость введенных символов.

## [1.0.25] - 2026-01-14
### Changed
- Порядок кнопок: в разделе интерфейсов кнопка «Сохранить» теперь отображается первой, перед кнопками «Добавить» и «Удалить».

## [1.0.24] - 2026-01-14
### Fixed

### Changed
- Оптимизированы npm-скрипты в `package.json`: добавлен скрипт `clean` для очистки `dist` и улучшена логика создания директорий в `copy:static`.

## [1.0.23] - 2026-01-14
### Added
- Визуальное различие: кнопка «Удалить» в разделе интерфейсов выделена красным цветом (стиль danger) для предотвращения случайных нажатий.
- Добавлена красивая SVG-иконка (favicon) в стиле Reticulum (узлы и сетевые связи), интегрированная в процесс сборки.
### Changed
- Единообразие интерфейса: кнопка «Сохранить» перемещена из нижней части форм в общий хедер страницы для всех разделов (WiFi, Ethernet, FreeDV), аналогично разделу Interfaces.

- Улучшение кнопок: текст на всех кнопках теперь центрирован по горизонтали.
- Индикация состояний: значительно улучшена визуальная обратная связь для заблокированных кнопок (изменение цвета фона, текста, границ и курсора).

## [1.0.22] - 2026-01-13
### Fixed
- Настройки интерфейса LoraSPI: исправлено отображение радио-параметров (Frequency, Bandwidth и др.), которые ранее не выводились из-за особенностей табличной вёрстки GPIO.

## [1.0.21] - 2026-01-13
### Added
- Настройки интерфейса LoraSPI: добавлены радио-параметры Frequency (MHz), Bandwidth (kHz), TX Power (dBm), Coding Rate и Spread Factor, аналогично интерфейсу RNode.

## [1.0.20] - 2026-01-13
### Fixed
- Настройки интерфейса RNode: исправлено поведение поля Bandwidth при полной очистке. Теперь предложения корректно возобновляются после начала ввода, а при пустом поле список подсказок скрывается.
- Числовые поля: добавлена поддержка дробных значений (`step="any"`), что устраняет ошибки валидации для дробных частот и полос пропускания.

## [1.0.19] - 2026-01-13
### Changed
- Настройки интерфейса RNode:
  - Выбор пресета: пустое значение заменено на «не выбран».
  - Поле Bandwidth: добавлена динамическая фильтрация вариантов выбора при вводе.
  - Поля Coding Rate и Spread Factor: теперь доступны только для выбора из списка (тип select), прямой ввод запрещен.

## [1.0.18] - 2026-01-13
### Added
- Настройки интерфейса RNode:
  - Добавлена возможность выбора радио-пресетов (Radio Presets), автоматически устанавливающих Coding Rate, Spreading Factor и Bandwidth.
  - Поддерживаемые пресеты: Short Turbo, Short Fast, Short Slow, Medium Fast, Medium Slow, Long Turbo, Long Fast, Long Moderate, Long Slow.
  - Автоматический сброс пресета при ручном изменении SF, CR или BW.

## [1.0.17] - 2026-01-13
### Changed
- Настройки интерфейса RNode:
  - Coding Rate: ограничено в диапазоне 5-8 (включительно).
  - Spreading factor: ограничено в диапазоне 5-12 (включительно).
  - Bandwidth: добавлен список предустановленных значений (7.8, 10.4, 15.6, 20.8, 31.25, 41.7, 62.5, 125, 250, 500, 1625 KHz) с сохранением возможности ручного ввода.

## [1.0.0] - 2025-11-18
### Added
- Начальная версия конфигуратора «RNS Gate — Configurator» (TypeScript + esbuild, без фреймворков).
- Разделы интерфейса: RNSD, FreeDV (отображение сырых данных), WiFi и Ethernet (специализированные формы).
- Форма WiFi:
  - Режимы: client/AP.
  - Получение текущей конфигурации через GET /wifi/info.
  - Переключение DHCP/Static, поля IP/Mask/Gateway/DNS1/DNS2.
  - Сохранение через POST /wifi/apply (application/x-www-form-urlencoded).
  - Подсказки/автозаполнение и локальный профиль (localStorage: profile_wifi).
- Форма Ethernet:
  - Получение конфигурации через GET /ethernet/info.
  - Переключение DHCP/Static, поля IP/Mask/Gateway/DNS1/DNS2.
  - Сохранение через POST /ethernet/apply (application/x-www-form-urlencoded).
  - Подсказки/автозаполнение и локальный профиль (localStorage: profile_ethernet).
- Статус-бар сети с индикацией: online, offline, busy, error.
  - Искусственная задержка смены цветов индикатора для мягких переходов.
  - Центрированное сообщение о состоянии/ошибках в верхней панели.
- Оффлайн-режим: корректная работа UI при открытии file:// и/или отсутствии сети (navigator.onLine = false).
  - В оффлайне специализированные формы рендерятся с дефолтами, запросы к CGI не выполняются.
- API-клиент (src/api.ts):
  - Базовый путь /cgi-bin (переопределяемый через window.CGI_BASE или window.__CGI_BASE__).
  - GET/POST с таймаутом, разбором ошибок и поддержкой JSON или текстовых ответов.
- Сборка через esbuild: bundle, minify, sourcemap → dist/bundle.js.
- Скрипты npm:
  - build — сборка.
  - copy:static — копирование index.html и styles.css в dist.
  - copy:server — копирование dist в локальный серверный проект (путь можно менять под окружение).
  - build:all — последовательный запуск сборки и копирования.
- Базовые стили интерфейса (styles.css): сайдбар, контент, формы, переключатели, статус-индикатор, код-блоки.
